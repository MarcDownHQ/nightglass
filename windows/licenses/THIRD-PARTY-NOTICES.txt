libmpv (libmpv-2.dll)
---------------------

libmpv-2.dll is mpv's player library, built by the mpv-winbuild project
(https://github.com/zhongfly/mpv-winbuild) in its "lgpl" variant:

- mpv is licensed under the GNU Lesser General Public License, version 2.1 or later
  (LGPL-2.1.txt). Source: https://github.com/mpv-player/mpv
- FFmpeg is linked into the same DLL and licensed under the GNU Lesser General Public
  License, version 3 or later (LGPL-3.0.txt, which adds permissions to GPL-3.0.txt).
  Source: https://git.ffmpeg.org/ffmpeg.git
- The DLL also contains libraries that mpv and FFmpeg use (for example libass, FreeType,
  HarfBuzz, FriBidi, dav1d, libplacebo, Little CMS, zlib), each under its own
  LGPL-compatible free licence. Their list and versions are in the build scripts:
  https://github.com/zhongfly/mpv-winbuild

libmpv-version.txt, next to this file, names the exact build and links the exact
source code it was built from: the mpv commit, the FFmpeg commit, and the commit of
the build scripts, which pin the versions of the other libraries.

Nightglass loads libmpv-2.dll at run time and does not modify it. You may replace
libmpv-2.dll in the installation folder with your own build of libmpv (same API,
version 2) and Nightglass will use it.


Rust crates
-----------

The Nightglass executable is compiled from Rust crates (Tauri, reqwest, quick-xml and
others). Their licences and copyright notices are in rust-crates.html, next to this file.


libmpv on macOS (Frameworks folder of the app)
----------------------------------------------

libmpv.dylib and the libraries next to it (FFmpeg, libass, FreeType, HarfBuzz, FriBidi,
dav1d, uchardet, libpng, libxml2, Mbed TLS) come from media-kit/libmpv-darwin-build
(https://github.com/media-kit/libmpv-darwin-build), "video-full" build: mpv built with
-Dgpl=false (LGPL-2.1 or later) and FFmpeg without --enable-gpl (LGPL-3.0 or later). The
exact build and where its sources are: libmpv-version.txt. The other libraries are each
under their own permissive or LGPL licence.

Fonts and icons
---------------

Nightglass uses fonts installed with Windows (Bahnschrift, Cascadia Mono, Segoe Fluent
Icons); none are shipped with it.

Where Segoe Fluent Icons is missing (macOS), icons come from NG Icons, a subset of
Fluent UI System Icons (MIT, Copyright (c) 2020 Microsoft Corporation;
https://github.com/microsoft/fluentui-system-icons) shipped with the app.
